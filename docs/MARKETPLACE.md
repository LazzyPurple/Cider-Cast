## Summary

Cast Cider to Google Cast speakers. Set up your Windows audio output once, then use Cider’s native controls.

## Description — 141 words

Cast music from Cider to your Google Cast speakers and groups. Other apps stay on your PC.

Setup

1. Install Cider Cast in Cider, then open the audio output menu.
2. Follow the link to install the Windows service. Close Cider, run the installer, then reopen Cider.
3. Click the settings icon beside the audio output heading and choose an unused Windows audio output, such as a secondary monitor. Keep this output connected and reserved for Cider.
4. Select your Cast speakers and start playing music.

Settings and controls

Use Cider’s native volume slider, playback controls and queue as usual. Choose “This computer” to return to PC playback. You can change the reserved Windows output from the plugin settings after closing and reopening Cider.

Requires Windows 11 x64, Cider Microsoft Store 4.0.32 or later, and speakers on the same local network.
